# GharKaPaisa Backend API

Node.js + Express + PostgreSQL API server for the GharKaPaisa platform.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Configure environment
cp .env.example .env

# 3. Run migrations
npm run migrate

# 4. Start dev server
npm run dev
```
