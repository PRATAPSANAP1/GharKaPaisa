## 🔐 Authorization Hierarchy

```
┌─────────────────────────────────────────┐
│ Public Routes (No Auth Required)        │
│ - Product listing (anonymous)           │
│ - Referral click tracking               │
└─────────────────────────────────────────┘
           ↓ User Logs In ↓
┌─────────────────────────────────────────┐
│ JWT Authentication Required             │
│ - All /api/v1 routes                    │
│ - All /partner/* routes                 │
└─────────────────────────────────────────┘
           ↓ Check Role ↓
    ┌──────────────────────────────────┐
    │ ROLE CHECKS                      │
    ├──────────────────────────────────┤
    │ requirePartner:                   │
    │ - User must be role PARTNER or    │
    │   have partner_profiles record    │
    │                                  │
    │ requireApprovedPartner:           │
    │ - Partner + KYC approved         │
    │ - Can access limited features    │
    │                                  │
    │ requireTeamMember:                │
    │ - User must be role TEAM_MEMBER  │
    │ - Cannot access team mgmt        │
    │                                  │
    │ selfOrAdmin:                      │
    │ - Access own data OR             │
    │ - Admin override (with ?param)   │
    └──────────────────────────────────┘
           ↓ Grant Access ↓
┌──────────────────────────────────────────┐
│ Data Scope (Based on Authorization)      │
│ - Partner: Own + downline data           │
│ - Team Member: Own data only             │
│ - Admin: All data                        │
└──────────────────────────────────────────┘
```

## 🔄 User Journey Comparisons

### Partner Journey: "Adding a Team Member"
```
1. Dashboard → [+ Invite Team Member]
2. Modal opens with form:
   - Full Name
   - Email
   - Mobile
   - Optional Password
3. System generates:
   ✓ Partner code
   ✓ WhatsApp link
   ✓ SMS link
   ✓ Email link
4. Partner sends invites
5. Team Member opens link
6. Team Member registers
7. Automatic parent assignment
8. KYC submission required
9. Admin approval
10. Team Member added to tree
11. Partner sees in: Dashboard → Team Network
12. Partner earns: 10% L1 + 5% L2 commission
```

### Team Member Journey: "Requesting Upgrade"
```
1. Dashboard → [Upgrade to Partner] button (Pink)
2. Click to open upgrade request modal
3. Form:
   - Reason for upgrade
   - Target team size
   - Optional notes
4. Submit request
5. Goes to Super Admin for approval
6. Notification when approved
7. Role changes to PARTNER
8. Unlocks:
   ✓ Team members section
   ✓ Reports module
   ✓ Team commission
   ✓ Full commission access
   ✓ Team analytics
   ✓ Full settings
9. Interface switches to Partner colors (purple)
10. All Team Member restrictions removed
```

## 🚀 Performance Optimization by Role

### Partner (Heavy Features)
- Server-side pagination (25-50 records)
- Lazy-load team tree nodes
- Image optimization (bank logos, profiles)
- CSV export batched (max 10,000 records)
- Indexed database queries for hierarchy

### Team Member (Lightweight)
- Reduced data payload
- Local filtering (client-side)
- Fewer API calls
- Simplified queries
- Single-tier data (own only)
